# Random-School-Games

## Got Bored (Android)

A lightweight C++20/SDL3 Android game collection with Chess (2 players), Air Hockey (2 players, multi-touch) and Snake, plus in-app updates via GitHub Releases.

* Source, build instructions and docs: [`MultiGameHub/`](MultiGameHub/README.md)
* Download the APK: [Releases](https://github.com/GL-328/Random-School-Games/releases/latest)
